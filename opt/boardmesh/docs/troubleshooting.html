How-to guide

Resolve common Boardmesh problems

The desktop says MCP offline

  1. Confirm that your MCP client initialized boardmesh-mcp and still keeps its stdio connection open.
  2. Check that the server did not use --no-runtime-ws.
  3. Compare the server's --runtime-addr with the GUI's --runtime-url.
  4. Run boardmesh-cli session.list --runtime-url ws://127.0.0.1:9467.
  5. Compare the GUI session with get_session_info in the agent client.

Launching the MCP executable with closed stdin does not create a background daemon. It needs a live MCP client. Use --no-runtime only when you intend file-only desktop editing.

The agent and person see different boards

  1. Compare absolute sessions directories.
  2. Compare session IDs and the returned scene path.
  3. Check the MCP server's active session.
  4. Add explicit session_id to each one-shot CLI request.
  5. Use one authority over the board files.

A relative path may point to different directories when the GUI and MCP client start from different working directories.

The runtime address is already in use

Check for an existing Boardmesh authority. Reuse it when it owns the intended board directory. For an independent board directory, choose another loopback port and configure the GUI and CLI to match. Do not run two authorities over the same files as a workaround.

boardmesh-mcp --sessions-dir /home/you/other-boards --session default   --runtime-addr 127.0.0.1:9468
boardmesh --sessions-dir /home/you/other-boards --session default   --runtime-url ws://127.0.0.1:9468

The MCP line remains an executable configuration for an MCP client, not a shell command that can run unattended with closed input.

An agent cannot find a tool

Inspect the client's actual tool list and call get_tool_help. Check the tool reference. Design documents and library models include capabilities that are not advertised MCP tools. In particular, do not call invented add_link, add_connector, or set_text tools.

An argument is rejected

  1. Read the specific tool's input schema.
  2. Use required field names exactly.
  3. Use IDs returned by the server.
  4. For triangles, provide either a rectangle or exactly three points.
  5. Inspect the error and read the scene before retrying a destructive operation.

MCP uses the active server session. CLI session scope is an additional runtime wrapper feature.

Undo or redo is unavailable

Undo history belongs to the current desktop window. Reopening starts a new history. A genuine external scene edit invalidates obsolete history. Current releases preserve history when delayed notifications merely echo already acknowledged local edits.

If delayed messages still break redo, verify that you use the updated release. Run the end-to-end verifier and keep its result.json and GUI log when reporting a bug.

The desktop cannot start

Check for a graphical display and the required GTK3, SDL 1.2, and OpenGL libraries. The Linux GUI binaries are dynamically linked. A headless terminal can use MCP and CLI, or run the GUI verifier under Xvfb. Use the installation guide's native build dependencies when building from source.

Icons look different outside the source checkout

The extracted binary uses built-in fallback icons when optional source icons are absent. This is an existing distribution limitation. The drawing tools remain available. Portable icon resources are tracked as separate design work.

A PNG is empty or incomplete

  1. Check that the active session contains the expected objects.
  2. Check visibility flags.
  3. For render_selected_png, confirm the selection first.
  4. Inspect the returned output path and crop bounds.
  5. Use a path writable by the MCP server process.

PNG output is a flattened scene image. Canvas metadata and GUI toolbars are not an editable part of that image.

Report a reproducible problem

Include the release tag or source revision, operating system, executable arguments with private paths removed, the smallest board that reproduces the problem, the exact tool call, and expected versus observed behavior. Include verifier evidence when available. Review board content before attaching it to a public issue.
