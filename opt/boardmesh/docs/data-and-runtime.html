Reference

Files, sessions, and runtime

Named sessions

A named board uses two files under the configured sessions directory:

my-boards/
  first-board.json
  first-board.manifest.json

The board JSON contains editable content. The manifest contains session metadata and GUI or server heartbeat records. Session IDs accept ASCII letters, digits, hyphens, underscores, and dots, but cannot be empty, ., or ...

Relative paths resolve from each process's working directory. Use absolute paths when a desktop process and an agent client must open the same files.

Scene and universe formats

A scene contains a version, background, selected object IDs, and drawable objects. An object has an ID, typed shape or text data, stroke, optional fill, visibility, and movement-lock state.

A universe contains an embedded scene plus viewport data, canvas frames, canvas selection, and object-to-canvas memberships. The storage layer reads legacy scene-only JSON and can migrate it to a universe document.

OperationWhat it preserves
Copy the original named-board JSONThe complete document as stored, including universe metadata when present.
get_universeThe universe in a response wrapper, including canvas data.
export_scene_jsonScene objects, styling, and object selection. It is not a complete universe backup.
PNG exportA flattened image and returned crop metadata. It does not retain editable objects.
GUI undo historyCurrent-window history only. It is not persisted as a durable operation log.

Runtime ownership

Use one runtime authority for a shared board directory. By default, the MCP server opens a local WebSocket listener at 127.0.0.1:9467. The GUI subscribes to updates and sends edits through the runtime. The CLI sends one JSON-RPC request per invocation. Files remain the persistence layer.

Live update messages tell the GUI that the board may have changed. Before applying a queued update, the GUI reads the current authoritative scene. This avoids rolling back the view or clearing redo when an older notification arrives after a newer acknowledged local edit.

MCP server flags

OptionMeaning
--session IDOpen a named session.

--runtime-addr ADDRSet the WebSocket listen address.
--no-runtime-wsServe MCP without the WebSocket bridge.
--help or -hPrint help and exit without creating board data.

Unknown arguments and missing option values fail before startup.

CLI request shape

boardmesh-cli list-methods
boardmesh-cli METHOD --runtime-url ws://127.0.0.1:9467 --json '{"session_id":"first-board"}'
boardmesh-cli call METHOD --json-file request.json --compact

call is an optional alias. The default output is pretty JSON. --compact prints compact JSON. --json-file takes precedence when both payload forms are supplied; use one form per command.

Runtime-only methods

The CLI exposes the same 40 operations as MCP plus these five runtime methods:

MethodRequest fieldsResult
session.attachsession_id optional, create_if_missing booleanCurrent runtime scene snapshot and connection scope.
session.listEmpty objectKnown sessions.
session.switchsession_id, create_if_missing booleanSnapshot for the selected session on that connection.
scene.getsession_id optionalRuntime snapshot, including scene and paths.
scene.replacesession_id optional, sceneThe replacement snapshot. This replaces scene content rather than merging objects.

A CLI invocation uses a new connection. A previous session.attach invocation does not establish scope for the next invocation. Pass session_id in each one-shot call. Long-lived runtime clients can retain their own connection scope.

Back up a board

Finish the active editing turn, stop writers for a consistent copy, and copy the original board JSON and manifest together. Keep the backup outside the extracted binary directory. Reopen a copied board against its intended sessions directory and verify its content before continuing work.

The JSON is a local file, not an encrypted vault. File permissions and any repository or backup service control access. The runtime is designed for local use and does not provide a hosted authentication or conflict-resolution service.
