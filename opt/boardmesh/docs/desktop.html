Reference

Desktop controls and editing behavior

The native editor opens a named session or a raw scene file. Without --session or --scene, it opens a session picker.

Drawing tools

ToolBehavior
SelectSelect objects, move unlocked objects, or drag a selection box. Ctrl-click toggles selection.
PenCreate a freehand stroke.
LineCreate a straight line. It is not automatically bound to nearby shapes.
RectangleDrag a rectangular shape.
CircleCreate a circular shape.
TriangleCreate a quick triangle or use the explicit three-point mode.
PolygonPlace points and finish the draft with Enter.
FillApply the selected fill color to a supported object.

Keyboard and camera

InputAction
Delete or BackspaceDelete selected objects.
Ctrl+ZUndo a local change.
Ctrl+Y or Ctrl+Shift+ZRedo a local change.

Middle-button dragPan the board.

Ctrl+2Fit the selection.

EscCancel the current draft.

Panels and layout

The workspace provides session, objects, inspector, and history panels. The default layout gives priority to the canvas. Contextual panels can appear when a drawing tool or new content makes them relevant. The View menu controls pane visibility and toolbar placement. Reset Layout restores the default arrangement.

The object list identifies objects and their selection. The inspector provides the current tool and styling controls. The status bar shows the session or raw-file mode, active tool, object and selection counts, and MCP connectivity.

Desktop options

OptionMeaning
--sessions-dir PATHChoose the directory for named board files.
--session IDOpen a named board.
--scene PATHOpen a raw scene file.
--runtime-url URLConnect to the local WebSocket runtime. Default: ws://127.0.0.1:9467.
--no-runtimeEdit local files without connecting to the runtime.
--tool NAMESet the initial drawing tool, such as select, line, or rectangle.
--triangle-mode MODEChoose quick or 3-point triangle behavior.
--filled-shapesStart with filled-shape drawing enabled.

Persistence and history

Completed changes persist to the scene. Undo history belongs to the current desktop window and is not a durable command log. New external scene content clears obsolete local history. Delayed echoes of acknowledged local changes preserve it. Reopening restores saved board content, not the previous window's undo stack.

Current presentation limits

Canvas frame metadata and semantic-link models are broader than the current desktop controls. Use the tool reference to distinguish available agent operations. Extracted binaries use fallback icons when optional source icons are unavailable.
