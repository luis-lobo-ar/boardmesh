# Boardmesh

A local desktop board that people and agents can edit together through MCP and CLI. Use it for design reviews, code explanations, incident timelines, and visual handoffs.

**[Read the complete documentation](https://luis-lobo-ar.github.io/boardmesh/)** · [First shared board](opt/boardmesh/docs/getting-started.html) · [Use cases](opt/boardmesh/docs/use-cases.html) · [People and agents](opt/boardmesh/docs/people-and-agents.html) · [Tool reference](opt/boardmesh/docs/tool-reference.html)

Clone and build without downloading other Mesh applications. Source builds require Rust 1.95 or newer. Binary users do not need a compiler.

```sh
git clone https://github.com/luis-lobo-ar/boardmesh.git
cd boardmesh
cargo build --locked --release -p boardmesh --bin boardmesh-cli --bin boardmesh-mcp
cargo test --locked -p mesh-graph -p mesh-id -p boardmesh
```

Linux x86_64 binaries and checksums are available under [Releases](https://github.com/luis-lobo-ar/boardmesh/releases). Extract the archive and add its `bin/` directory to PATH. Snapshot releases are prereleases built from the exact source revision below.

Product source and manuals: [opt/boardmesh](opt/boardmesh/). [Standalone guide](DISTRIBUTION.html). Shared crates under `lib/` are generated from the same Mesh revision and are included only when this product needs them.

Authoritative development: the Mesh monorepo. This repository receives generated snapshots. Open issues here; proposed changes must be integrated into Mesh by its maintainer before the next snapshot. Do not edit the generated shared crates independently.

Source commit: `da7d64f83b5cfef480b61c7f795c18bdd2076ee2`. Full file hashes and exporter provenance: [mesh-export.json](mesh-export.json). No private monorepo history, active task records or session data are included.

MIT licensed Mesh code; third-party assets retain the notices in LICENSES.txt and their original licenses.

Desktop build: install GTK3, SDL 1.2, CMake, Clang/libclang, OpenGL and pkg-config development packages; then `RUSTFLAGS='-C link-arg=-lSDL' cargo build --locked --release -p boardmesh --features gui`. MCP: run `target/release/boardmesh-mcp --session default`.

Read the [Boardmesh manual](opt/boardmesh/README.html) and [installation and verification guide](opt/boardmesh/docs/install-and-verification.html). Boardmesh runs without another Mesh service. The snapshot workflow verifies extracted GUI, MCP and CLI binaries together before publishing.

Initial binary limitation: desktop icons use the built-in fallback shapes when the source checkout is absent. The current GUI loads optional Font Awesome SVGs from its compile-time source path. Source builds retain those icons; relocatable asset lookup is future product work.
